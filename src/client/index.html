Welcome

This is a simple 3rd-person aim trainer using Three.js. Move around and shoot the targets in the time limit to try to get a high score, or make things more difficult for yourself by decreasing target radius and count.

Controls

Select mouse and keyboard controls to use WASD and the mouse to aim. Fire with LMB and jump with space. You can also connect a controller and use LS to move, RS to aim, RT to fire, and A/B to jump. Note: I was only able to test / make button maps for a Switch pro controller and Xbox One controller, and only Chrome and Safari took the inputs correctly with a wired connection. If you are wondering if your controller is connecting properly, try testing with a Gamepad API tester.
